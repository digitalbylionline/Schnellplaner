# START HIER – Nutrition Intelligence Brain

Wissensbasis für einen deutschsprachigen Faceless-Account (Instagram, TikTok, YouTube Shorts) zu Ernährung, Körpergesundheit und evidenzbasierter Ernährungsaufklärung.

> [!important] Rangfolge
> **1. Wissenschaftliche Korrektheit → 2. Sicherheit → 3. Rechtliche Zulässigkeit → 4. Reichweite → 5. Monetarisierung.**
> Kein Inhalt verlässt dieses System ohne menschliche fachliche **und** rechtliche Freigabe. Claude erteilt keine Freigaben.

## So funktioniert der Wissensfluss

```
Quelle (09) ──► Forschungsakte (01–04) ──► Qualitätskontrolle (00/QB) ──► Video-Briefing (07) ──► Freigabe (06) ──► Veröffentlichung
                        ▲                                                                              │
                        └──────────────── Korrekturen / neue Studien ◄─────────────────────────────────┘
```

1. Jede Aussage stammt aus einer **Quelle** im [[Quellenregister]].
2. Aussagen werden in einer **Forschungsakte** gesammelt und je Aussage bewertet (Evidenz A–D, Werberecht W, Redaktion R) – siehe [[Evidenzstufen_und_Statussystem]].
3. Ein Video darf nur aus einer Akte mit Status **R1 (fachlich geprüft)** oder höher abgeleitet werden – Vorlage: [[Vorlage_Video]].
